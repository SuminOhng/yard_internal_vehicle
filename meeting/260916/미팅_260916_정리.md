# 2026년 9월 16일 미팅 정리

녹음: 미팅_260916.m4a / 길이: 18분 58초

이 문서는 자동 전사 결과를 바탕으로 작성했다. 논문 원문이나 발표 자료는 제공되지 않았으므로, 논문의 결과·가정은 회의에서 설명된 내용으로 기록한다. 화자 실명은 확정하지 않고 발표자와 지도자로 구분한다.

## 핵심 결론

유인·무인 내부 트럭이 혼재하는 터미널에서, 유인 트럭은 최단 경로를 이용한다는 가정을 유지하고 작업 배정을 조정한다. 무인 트럭은 작업 배정과 경로를 함께 조정해 유인 트럭과의 시간대별 간섭을 피하고 크레인 인계 시각에 맞춘다.

문헌 조사를 계속하면서 이 구조의 작은 시뮬레이터를 먼저 만들기로 했다. 한 번에 모든 작업을 배정하는 실험에 그치지 않고, 작업을 끝낸 차량에 다음 작업을 순차적으로 배정하는 반복 운영까지 비교하는 것이 핵심이다. 이번 회의에서 새 실험의 정량적 성과가 제시된 것은 아니다.

## 1. 문헌 검토와 연구 배경

### 혼재 운영 데이터 분석 논문

발표자는 실제 터미널 데이터를 이용해 유인·무인 트럭의 운영 소요시간을 여러 예측 모델로 비교한 2025년 논문을 소개했다. 약 2만 건의 데이터가 언급됐다.

- 혼재 운영은 유인·무인 차량이 장벽이나 차로 분리 없이 같은 공간을 사용하는 상태로 설명됐다.
- 대상은 수평형 레이아웃으로, 현재 관심 있는 연구 환경과 관련성이 있다고 판단했다.
- 새로운 최적화 정책을 제안한 논문은 아니며, 기존 시계방향 통행 규칙 아래의 운영 데이터를 분석한 것으로 설명됐다.
- 저부하에서는 혼합 운영이, 고부하에서는 완전 자동화가 유리하다는 결과가 소개됐다.
- 무인 차량은 크레인 아래 불필요한 대기를 피하도록 작업 시각에 맞추고, 유인 트럭은 가능한 한 빨리 도착하려는 특성이 언급됐다.

**확인 필요:** 작업량 경계는 한 구간에서 ‘50개 이상’, 다른 구간에서 ‘5개 이상’으로 인식됐다. 차량 유형별로 어느 쪽이 더 오래 걸리는지 설명도 일부 상충한다. 정확한 수치와 비교 조건은 원문 확인 전 인용하지 않는 것이 좋다.

### 연구 질문

자동화 전환기에 유인·무인 차량이 공존하는 것은 불가피할 수 있다. 따라서 저부하뿐 아니라 작업이 집중되는 고부하에서도 혼재 환경을 효율적으로 운영할 수 있는 배차·경로 정책을 찾자는 방향이 제시됐다.

‘혼잡 감소가 효율 향상으로 이어진다’는 연결은 연구의 근거로 보강할 필요가 있다고 논의됐다. 아직 입증된 결과로 취급하지 않는다.

### 기존 연구와의 구분

- 기존 디스패칭 논문: 에너지 소비, 작업 완료 시간, 작업량 균형을 고려한 유·무인 차량 배정.
- 기존 라우팅 논문: 유인 차량의 경로 선택을 가정하고 무인 차량의 경로를 재선택. 20%의 다른 경로 선택 가능성이 언급됨.
- 새로 찾은 통합 관련 논문: 무인 내부 차량과 게이트를 오가는 유인 외부 차량의 교차 구간을 다루는 것으로 잠정 파악. 아직 충분히 읽지 않았고 GPT 설명에 의존한 부분이 있음.
- 추가 후보: 최단 경로 외 대체 경로를 마련해 혼잡을 예방하는 논문. 회의 당시 미독 상태.

현재 구상은 **내부 운송을 수행하는 유인·무인 트럭의 혼재**에 초점을 둔다. 외부 트럭과의 교차만 다루는 연구와 대상·제어 범위를 구분해야 한다. 새 논문의 저널명은 정확히 인식되지 않아 확정하지 않았다.

## 2. 제안된 실험 모델

### 작업과 환경

- 격자형 도로망을 초기 가정으로 둔다.
- 수평형 터미널과 한진 관련 데이터를 참고해 작은 사례부터 구성한다.
- 작업마다 어느 블록에서 무엇을 받거나 내려놓는지와 인계 목표 시각을 정의한다.
- 작업 10개 또는 100개, 유인·무인 트럭 각각 5대 등의 숫자는 예시로 제시됐다. 확정된 실험 규모는 아니다.
- 야드와 안벽의 작업을 동기화해야 하므로, 무조건 빨리 도착하는 것보다 크레인이 작업할 수 있는 시각에 맞춰 도착하는 것이 중요하다.

### 유인 트럭

1. 배정된 작업에 대해 최단 경로를 이용한다고 가정한다.
2. 해당 가정 아래에서는 작업 배정이 경로를 사실상 결정한다.
3. 유인 트럭끼리 같은 시간에 같은 구간에서 간섭하지 않도록 작업 조합을 고른다.

여기서 ‘경로가 겹치지 않는다’는 것은 공간적으로 영원히 다른 길을 써야 한다는 의미가 아니라, 같은 시간대의 충돌·간섭을 피한다는 취지다.

### 무인 트럭

1. 나머지 작업을 배정한다.
2. 유인 트럭의 이동과 간섭하지 않도록 우회·대기 등을 포함한 경로를 계산한다.
3. 우회하더라도 정해진 인계 시각에서 가능한 한 벗어나지 않도록 한다.

유인 트럭에 배정할 작업 조합을 바꾸면 무인 트럭에 남는 작업과 경로도 달라진다. 이 조합을 반복적으로 바꿔 더 좋은 운영 계획을 찾자는 제안이다. 무인 차량만 경로 최적화를 풀기 때문에 계산 부담이 줄 수 있다는 기대가 있었지만, 아직 검증 결과는 없다.

## 3. 시간 목적과 용어 주의

발언에서는 ‘tardiness’를 언급하면서 목표 시각보다 늦거나 일찍 도착하는 것 모두에 페널티를 주자는 취지가 포함됐다.

모델을 작성할 때는 다음을 구분해야 한다. 아래는 회의 취지를 명확히 하기 위한 정리이며, 회의에서 확정한 수식은 아니다.

- 목표 인계 시각: d, 실제 도착 시각: a
- 지각(tardiness): max(0, a − d)
- 조기 도착(earliness): max(0, d − a)
- 양쪽을 모두 벌점화한다면 두 항의 가중합 등을 검토한다.

최종 모델에서는 도착과 실제 서비스 시작 중 무엇을 기준으로 할지, 조기 도착 차량의 대기를 허용할지, 목표 시각을 강제 제약으로 할지 페널티로 할지를 정해야 한다. 이 세부 사항은 회의에서 확정되지 않았다.

## 4. 반복 운영과 비교 정책

초기에 여러 작업을 한꺼번에 배정한 뒤, 차량이 작업을 마칠 때마다 가용 차량과 남은 작업을 갱신해 다음 작업을 배정한다. 디스패칭과 라우팅을 계속 반복했을 때 어떤 정책이 좋은지 평가한다.

회의에서 언급된 비교 후보는 다음과 같다.

| 정책 | 작업 배정과 경로 처리 | 해석상 주의 |
|---|---|---|
| 단순 기준안 | 무작위 배정 + 전체 차량 최단 경로 | 간섭 발생 시 처리 규칙은 추가 정의 필요 |
| 전체 제어 비교안 | 모든 차량을 제어 가능한 차량처럼 보고 배정·라우팅 수행 | 실제 유인 운전 제약을 완화한 비교 조건 |
| 제안안 | 유인 차량의 작업·최단 경로를 먼저 정하고 무인 차량을 배정·라우팅 | 인계 시각과 시간대별 간섭을 함께 고려 |

배정 일부를 파괴하고 복구하는 탐색 알고리즘도 후보로 언급됐다. 자동 전사는 ‘ANS’로 인식했으므로 정확한 알고리즘명은 확인이 필요하다. 특정 알고리즘을 최종 채택한 것으로 보지는 않는다.

## 5. 후속 할 일

별도 담당자 이름이 명확히 구분되지 않아 아래 구현·조사 작업은 발표자에게 제안된 것으로 정리했다.

1. 이번 회의의 모델 가정과 실험 방향을 기록한다.
2. 작업의 출발·도착 위치, 인계 목표 시각, 차량 수를 정의한다.
3. 유인 트럭 최단 경로와 시간대별 간섭을 표현하는 작은 시뮬레이터를 만든다.
4. 무인 트럭의 우회·대기·배정과 도착 시각 페널티를 추가한다.
5. 유인 차량에 배정하는 작업 조합을 바꾸며 무인 경로를 다시 계산한다.
6. 일회성 계획에서 작업 완료 후 다음 작업을 배정하는 반복 운영으로 확장한다.
7. 단순 기준안, 전체 제어 비교안, 제안안을 같은 조건에서 비교한다.
8. 문헌 조사를 병행하고 내부 혼재·외부 차량 교차·완전 자동화 연구를 구분한다.

**일정:** 빠르게 초기 모델을 만들어 보자는 요청은 있었으나, 이번 녹음에서 구체적인 제출일이나 다음 미팅 날짜는 확인되지 않았다.
